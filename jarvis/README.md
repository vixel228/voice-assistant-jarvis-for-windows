# Джарвис — голосовой помощник для Windows

Голосовой ассистент на Python с режимом **push-to-talk**: звук пишется только
пока зажата комбинация **Ctrl + Windows**. Ответы озвучиваются **нейросетевым
человеческим голосом** (edge-tts, голоса Microsoft: «Дмитрий» и «Светлана»),
при отсутствии интернета автоматически используется русский голос Windows (SAPI).

Сменить голос: «смени голос», «мужской голос» или «женский голос».
Для проверки без микрофона есть текстовый режим `-t`.

Новые возможности (заметки, скриншоты, таймеры, валюты, мониторинг и т.д.)
добавлены поверх; полный список команд — в таблице ниже.

## Установка

1. Из папки проекта:

   ```
   py -3 -m pip install -r requirements.txt
   ```

2. Убедитесь, что в системе есть русский голос:
   Параметры → Время и язык → Речь → добавить русский голос
   (в Windows обычно есть «Ирина»/«Дмитрий», они подхватятся автоматически).

## Запуск

```
run.bat                — голосовой режим (push-to-talk)
py -3 jarvis.py        — тоже голосовой режим
py -3 jarvis.py -t     — режим с клавиатуры (тест без микрофона)
```

## Как пользоваться

**Зажмите Ctrl + Windows и говорите команду. Отпустите — Джарвис ответит.**
Слово «Джарвис» больше говорить не нужно — ассистент отвечает на любые фразы.

Звуковые сигналы: восходящий «бип-бип» — начал слушать, одиночный низкий бип — услышал.

## Возможные проблемы

- Нет микрофона или распознавание молчит — используйте `py -3 jarvis.py -t`.
- Нейроголос требует интернета; без сети Джарвис автоматически переходит на системный русский голос (SAPI).
- Если системного русского голоса нет — Параметры → Время и язык → Речь → добавить русский голос.
- Распознавание требует интернета (работает через Google Speech).
- Если `python` в PATH не настоящий (заглушка Microsoft Store), всегда запускайте
  через `py -3` или `run.bat`.
